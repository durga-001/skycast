# SkyCast 

🔗 **Live Demo:** [skycast.com](https://skycast-frontend-vqhq.onrender.com/ocean-dashboard)

---

## Overview
SkyCast is a full-stack, microservices-based weather dashboard built during my Web Developer Trainee role at DRDO. It provides **real-time weather and ocean data** with personalized forecasting and outfit recommendations.

## Features
- **Live Weather + Ocean Data**  
  Integrated **OpenWeather API** and **Storm Glass API** to deliver combined atmospheric and sea-state insights.

- **Event-Driven Architecture**  
  Leveraged **WebSockets** for asynchronous, event-driven data processing and live updates.

- **Forecasting Modules**  
  Weekly and monthly forecasts with an intelligent **outfit recommendation system** based on predicted conditions.

- **Secure & Scalable**  
  Implemented **JWT authentication** and RESTful APIs following clean code principles.
